# Contributing

Use a legitimate Steam installation of Ravenfield and follow the build instructions in [README.md](README.md). Run the offline verification script. If you test in-game, include the Steam build, map, game mode, controller setup, and which player was affected.

Keep pull requests focused. Commit original mod source, build scripts, configuration templates, and documentation. Keep game assemblies, extracted assets, decompiled sources, third-party binaries, local logs, and build output out of Git. Reference the game's assemblies from a local installation.

For bug reports, include reproduction steps and a short relevant log excerpt with personal information removed. For changes to runtime patches, name the game methods affected and describe what was tested.
